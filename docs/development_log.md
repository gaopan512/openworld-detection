# 集中审查与修复记录

## 2026-10-20

本记录仅描述本轮已完成的修改与实际验证，不代表所有平台均已验证。

### 本轮修复

- 相同类别只调节阈值时复用文本类别设置与预测器；类别变化后重新设置。类别设置失败时允许重试，不缓存失败状态。
- 长类别标签通过二分查找缩短类别名称，为置信度保留宽度；图片太窄或太矮时保留检测框。减少长文本逐字符测量产生的重复计算。
- 检测器拒绝空类别、非字符串类别和非法阈值，包括布尔值、NaN 与无穷值。
- 保存与打开图片对话框期间暂停自动检测，阻止已排队的自动任务启动；关闭对话框后恢复有效的待执行任务。保存使用进入对话框前的结果快照。
- 原图预览与检测统一处理 EXIF 旋转、镜像。检测失败时清除旧参数说明，结果参数包含模型与最终设备。
- 图片读写通过字节编解码处理中文文件路径。验证脚本保存前创建目录。
- GUI 支持自动选择、MPS、CUDA、CPU。自动选择加速设备后失败时显示原因并用 CPU 重试一次；重试失败则报告两次错误。手动指定设备不回退。
- 检测耗时明确包含模型加载、文本编码、推理和 CPU 重试，不包含绘图、保存；不作为纯推理基准。
- 命令行检测脚本默认 CPU，可指定 MPS/CUDA；实验脚本坚持指定设备，不自动回退。原生 YOLO-World 验证脚本的执行入口受到 main 保护。
- 实验 JSON 写入临时文件后替换，避免普通写入中断破坏上一份完整记录。
- 添加直接依赖版本清单、CLIP 固定提交及 Conda 环境入口，Windows 时区数据库通过条件依赖补齐。统一测试入口包含提示词解析测试。
