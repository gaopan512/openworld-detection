## 本次验证

在现有 macOS arm64 的 `openworld-detection` Conda 环境中执行：

```bash
QT_QPA_PLATFORM=offscreen python -B -m unittest discover -s tests -v
python -B scripts/verify_real_inference.py --device cpu
```

- 62 项回归测试全部通过，覆盖输入解析、检测参数与缓存、设备选择、GUI 状态、保存、权重校验下载及实验目录管理。
- 真实 CPU 推理通过 Qt 后台线程返回 GUI 结果，并保存、重新读取 PNG；`data/demo/bus.jpg` 输入 `person, bus`，检出 5 个目标，输出尺寸 810 × 1080。
- 本次 GUI 验证采用 offscreen 模式。此前开发记录中的 macOS 人工验收涵盖页签、缩放拖动、高亮、自动检测及 PNG/JPEG 保存；本次未重新进行人工桌面验收。
- 课程报告中的实验数值与本地已有统计汇总核对一致。本次未重跑 120 组实验和耗时测量。

测试和验证工具按已有仓库发布范围保留在本地，不随公开仓库分发；以上命令适用于完整开发工作区。公开仓库的验证入口为 README 中的安装、模型准备与示例图操作流程。

## 实验结果与边界

默认阈值 0.25、同类别 IoU ≥ 0.50 时，TP=66、FP=53、FN=64，Precision=55.46%、Recall=50.77%、F1=53.01%。详见[统计汇总](实验摘要/统计汇总.json)与[固定实验协议](实验摘要/protocol.json)。

样本限定为六组共 24 张图片，指标仅覆盖预先指定词汇，不是 COCO 全集 mAP，也不验证未见类别泛化能力。小目标、食物类别和标注粒度差异仍会影响表现；相关失败案例保留于课程报告。
