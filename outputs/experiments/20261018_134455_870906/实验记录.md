# 提示词与置信度阈值实验

- 实验日期：2026-10-18，Asia/Shanghai。
- 输入图片：`data/demo/bus.jpg`。
- 模型：`models/yolov8s-worldv2.pt`，实际推理设备：CPU。
- 每次只改变提示词或阈值；同一个模型实例顺序运行五组条件。
- 五组实验均完成，结果图片尺寸与原图一致，图片和原始检测记录均已保存。

## 本次观察

| 条件 | 实际输出观察 |
|---|---|
| `person, bus`，阈值 0.25 | 输出 person 和 bus 检测框；bus 分数约 0.889，person 分数约为 0.618 至 0.912。 |
| `person, bus`，阈值 0.50 | 本次输出与 0.25 条件相同；基线中没有低于 0.50 的输出。 |
| `person, bus`，阈值 0.75 | 基线中约 0.618 的 person 检测框不再输出，其余检测框保留。 |
| `pedestrian, bus`，阈值 0.25 | 输出 pedestrian 和 bus；pedestrian 分数约为 0.298 至 0.537，与 person 提示词产生不同结果。 |
| `person, coach`，阈值 0.25 | 输出 person，本次没有输出 coach 检测框。 |

这些观察说明：阈值可以过滤较低分数的输出；改变类别短语可能改变置信度和检测框。不能据此认定 pedestrian 普遍不如 person，或模型无法检测所有 coach。不同词语的含义也不完全相同。

没有人工真值标注，因此不报告准确率、召回率或 mAP；模型分数不是准确率。本次不做推理速度或 CPU/MPS 性能比较，也未验证 MPS。

## 重复实验

在项目根目录、已激活项目环境的终端执行：

```bash
python -B scripts/run_prompt_experiments.py --device cpu
```

每次运行生成新的时间目录，不覆盖本次结果。软件环境和底层计算仍可能影响重复运行结果；环境版本与输入文件哈希记录在 JSON 中。
